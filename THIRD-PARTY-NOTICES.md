## Swiss Ephemeris browser package

- Package: `@swisseph/browser` version `1.4.0`
- Upstream source: https://github.com/swisseph-js/swisseph
- License: AGPL-3.0
- Contains Swiss Ephemeris code (copyright Astrodienst AG, Zurich, Switzerland) and Moshier algorithms.
- The deployed local runtime is generated by `.github/workflows/vendor-swisseph.yml` from the published npm package without editing its contents.
- Corresponding original source and build instructions are available at the upstream repository; this project's integration source is in `js/ephemeris.js`.
- The CDN fallback loads the same package version when the local import, WASM initialization, or position calculation fails.

The built-in Moshier mode requires no external planetary data files. This app does not call `loadStandardEphemeris()`.
